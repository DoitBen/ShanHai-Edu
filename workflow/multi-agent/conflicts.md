# 多角色协作冲突台账

## 使用规则

- 当两个或多个角色对同一事项给出不同结论时，必须写入本台账。
- 写入冲突不代表立即裁决；裁决前不得覆盖共享事实。
- 裁决后同步更新 `workflow\multi-agent\shared-facts.md` 和 `workflow\multi-agent\decisions.md`。
