## 主画像 P01：李雪老师（v1 核心用户）

### 一句话定义

**一名想凭一节区级公开课冲职称的县市级小学数学骨干教师，时间紧、压力大、追求作品感、抗拒"AI 味"。**

### 基础信息

| 项目 | 内容 |
|---|---|
| 化名 | 李雪 |
| 年龄 | 32 岁 |
| 教龄 | 8 年 |
| 学校 | 地级市某区中心小学（非顶尖名校，非农村校） |
| 职务 | 二年级数学教师 + 班主任 |
| 职称 | 一级教师，正在评高级 |
| 月可支配工具预算 | 50-200 元 |

### 当前处境（产品被使用的触发场景）

- 下个月要开一节**区级公开课**——例如"万以内加法（一次进位）"
- 评课结果计入评优档案，**直接影响下一轮职称晋升**
- 距公开课还有 30 天，正常教学不能停，每天可投入 1-2 小时
- 教研组组长答应给意见，但具体内容必须她自己产出
- 她已经被同事推荐过几款 AI 教学工具，**都不够"上得了台面"**

### 痛点清单（按强度排序）

| 强度 | 痛点 | 产品如何回应 |
|---|---|---|
| ★★★★★ | 上次公开课被评委说"PPT 太套路、没特色"，这次必须有视觉震撼力 | PPT 视觉资产必须有真实生活场景图、丰富视觉元素 |
| ★★★★★ | 试过的 AI 工具（豆包/文心/Kimi）"生成的教案要大量改" | 字段化 schema + 飞轮注入用户偏好，减少改稿量 |
| ★★★★☆ | 想做导入视频但不会——剪映只会简单剪辑，做不出"故事感"，也怕视频变成提前讲知识点的小课 | 9 套导入视频策划卡 + 课堂接入说明；视频只通过课程锚点接回课堂 |
| ★★★★☆ | **怕"AI 味"被评委一眼识破**——必须像她自己写的 | 飞轮学习其偏好；编辑通道可改字 |
| ★★★☆☆ | 完美主义和时间冲突——想做 90 分，但只有做 60 分的时间 | 9 步流水线 + approve 即固化，不反复横跳 |
| ★★★☆☆ | 数学内容怕错——评委一抓一个准的扣分点 | 字段 8（精确数学内容）+ 可编辑文本层硬约束 |

### 用户目标（按优先级排序）

1. 拿到一节"卧槽这能上"的完整课件（教案 + PPT + 1-2 分钟导入视频）
2. 课件要有自己班级的影子（角色形象、生活场景接近学生）
3. 数学内容零错误（公式、单位、答案）
4. 备课时间从 30 天压到 7-10 天，剩下时间留给磨课、试讲、改稿

### 导入视频真实意图（v1 必须遵守）

当本课需要导入视频时，李雪老师要的不是"把教案开头拍成视频"，也不是"提前把本课知识点讲一遍"。她真正想要的是一支独立、有吸引力、能抓住学生注意力的短视频，视频本身可以是科普、生活冲突、故事任务或奇妙现象，最后再自然接回本课学习任务。

因此，教案里的"导入设计"必须拆成两层：

1. **导入视频策划卡**：负责独立创意，包括视频主题、开场钩子、吸睛点和故事/现象，不受教案流程过度限制。
2. **课堂接入说明**：只负责课程锚点、课堂落点问题、接入教案的位置和不提前讲解的内容。

导入视频和教案之间唯一硬连接字段叫**课程锚点**。课程锚点只回答："这个视频最后，通过什么现象、问题、物品、冲突或任务，和本课课题发生关系？"它不负责提前讲定义、方法、结论或课堂探究步骤。

典型例子：如果课题是"认识三角形"，视频可以做"为什么桥梁、塔吊、屋顶都喜欢三角形"的科普导入，最后通过"三角形结构反复出现"接回课堂，而不是在视频里直接讲三角形定义。

### 技术能力 & 工作习惯

- **会用**：PowerPoint、企业微信、剪映（基础剪辑）、希沃白板、班级群发通知
- **不会用**：代码、命令行、API、prompt 工程、复杂参数面板、Git
- **典型操作路径**：填表 → 看结果 → 满意保存 → 不满意改一改 → 不行就重做
- **不接受**：让她"调参数"、"写提示词"、"理解工作原理"

### 决策心理（在产品里点按钮时她在想什么）

| 当她看到… | 她的反应 |
|---|---|
| AI 生成的 6 字段教案 | 先看"教学流程"和"教学目标"，对标新课标，对不上就否决 |
| AI 给的 9 套导入视频策划卡 | 先看哪个视频主题最吸引学生，再看最后能不能通过课程锚点自然接回本课；不希望视频被教案流程绑死 |
| PPT 页面预览 | 第一眼看视觉，第二眼找数学错误，第三眼想"评委会怎么看" |
| AI 生成的视频 | 怕角色是"真人小孩"（合规问题），怕配音是女声（她要男声更稳重），也怕视频一上来就把知识点讲完，课堂反而没悬念 |
| "高级配置"折叠面板 | **直接跳过**，假装看不见 |
| 红色"硬阻断"警告 | 紧张，立刻照着做 |
| 一长串"进度日志" | 看不懂但有安全感（"系统在工作"） |

### 她对产品的最高期待

> **"我填一些课题信息，系统给我一节完整的好课，我审一审、改一改、就能去上。"**

不是"AI 帮我提效"，是"**AI 给我作品**"。

### 红线（产品绝不能踩）

- 生成的角色是真人小孩 → 合规事故，直接停止使用
- 生成的数学内容有错 → 评委扣分，立刻失信
- 配音是女声或机械感太重 → 公开课失格
- 让她在 30 天内学会一套"提示词工程" → 直接放弃产品
- 要求她连接命令行、配置 API key → 直接放弃产品

## 次画像 P02：王教研员（v1.x 扩展用户）

### 一句话定义

**地级市教研室小学数学教研员，关心的是"批量供给优质课件 + 培养区域骨干"，不是单节课。**

### 关键特征

- 年龄 45 岁，教研工龄 15 年
- 管辖区域内 60-80 所小学的数学教研
- 每学期组织 4-6 场区级公开课，需要产出参考课件
- 关心：**课件的可复用性、风格一致性、新课标对齐度**
- 不关心：单个老师的便捷度
- 决策权：能拍板"全区推荐使用某个工具"

### 与主画像的差异

| 维度 | 李老师 P01 | 王教研员 P02 |
|---|---|---|
| 用法频率 | 一学期 1-2 次 | 一学期 10+ 次 |
| 关心重点 | 我自己这节课能不能上台 | 全区课件的均值水平 |
| 验收口径 | 评委说"有特色" | 公开课档案 + 区域参评 |
| 付费意愿 | 个人 100-200 元/年 | 区域订阅 1-10 万元/年 |

> **v1 阶段，王教研员不是核心服务对象**——所有功能优先满足李老师。v1.x 再考虑王教研员的批量管理、风格库共享、区域看板等需求。

## 反画像（不是我们的用户）

| 反画像 | 为什么不是 |
|---|---|
| 大学教师 | 内容粒度、教学法、合规要求都不同 |
| 培训机构老师 | 不办公开课，不需要"作品级"震撼力 |
| 农村教学点教师 | 网络/设备/审美需求差异大，v1 不覆盖 |
| K12 学科类校外培训师 | 政策风险，主动回避 |
| 初中、高中数学教师 | v1 只锚定小学数学 |
| AI/教育产品设计师（同行尝鲜） | 不是付费用户，不优化体验 |
