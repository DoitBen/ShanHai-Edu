# 媒体生成工作台 v2 需求文档

## 一、现状缺陷

### 1. 不是真正的批量生成

- 当前图片"张数"(1/2/3/4)是**同一个提示词生成多张**,不是多个独立提示词并发
- 用户如果要生成 5 张不同主题的图片,需要手动提交 5 次,每次等一张
- 缺少"多行提示词,每行一个任务,一起提交"的批量模式

### 2. 无并发机制

- `ConfigScreen` 的"并发数"配置(1-8)是纯本地 state,没有通任何后端
- 视频任务创建后只能一个一个同步,没有自动轮询队列
- 类型定义 `runtime_concurrency.supports_multi_worker: false` 写死了单 worker

### 3. 模型列表硬编码

- 图片模型选择器只显示一个选项 `gpt-image-2`,视频只显示 `omni_flash-10s`
- 后端已返回 `capabilities.image.models[]` 和 `capabilities.video.models[]` 数组,包含每个模型的 `sizes`、`qualities`、`max_count`
- 前端没有动态渲染这些模型列表,漏掉了 **MiniMax** 等可用模型

### 4. 比例选择不直观

- 尺寸选择器是裸分辨率字符串: `1920x1080`、`1024x1024`、`1080x1920`
- 用户看不懂这些数字对应什么比例
- 应有 1:1、4:3、16:9、9:16 等可视化预设

### 5. 画质选项不全

- 只有 `high` 和 `low` 两档,缺少 `medium`
- 应该三档: low / medium / high

### 6. 布局比例不合理

- **图片 Tab**: 左操作区 0.9fr,右结果区 1.1fr -- 结果区比操作区还大
- **视频 Tab**: 右任务队列 340px 固定,纯列表无预览

### 7. 右侧结果区功能不足

- 图片结果是**全尺寸大图网格**,一张图占很大版面
- 没有缩略图模式,空间浪费
- 点击图片不能放大查看,只能勾选(用于加入参考篮)
- 不能单独下载某张图,只能去素材篮里找

### 8. 缺少视频结果缩略图区

- 视频 Tab 右侧只有任务列表(状态文字+进度条),看不到生成的视频画面
- 视频完成后要切到"素材篮/历史"Tab 才能看到

### 9. 代码结构问题

- `AdminMediaWorkbenchScreen.tsx` 731 行单文件,10+ 个子组件内联定义
- 图片、视频、素材三个 Tab 逻辑没有拆分
- 后续加批量、并发、缩略图等功能会继续膨胀

### 图片 Tab 具体要求

- 左侧操作区占 60-65% 宽度
- 右侧缩略图区占 35-40%,网格 2-3 列小图
- 缩略图点击弹出全屏预览弹窗,支持键盘左右切换、下载
- 缩略图上显示勾选框,支持批量选中 → 加入参考篮

### 视频 Tab 具体要求

- 左侧与图片 Tab 保持一致的占宽比例
- 右侧改为缩略图+任务卡片混合模式:
  - 已完成的任务显示视频缩略图
  - 进行中的显示进度条卡片
  - 失败的显示错误卡片
- 视频缩略图可点击播放或下载

## 三、功能需求

### F1: 批量图片生成

**入口**: 图片 Tab 操作区新增"批量模式"切换

- 普通模式(现有): 一个提示词 + count 张数
- **批量模式(新增)**: 多行文本框,每行一个独立提示词
  - 提交时每个提示词创建独立任务
  - 共享同一组参数(模型/比例/画质)
  - 后端支持并发提交,`ImageWorkbenchRunRequest` 改为 `requests` 数组或分次调用

**接受标准**:
- 批量模式下可输入 1-20 行提示词
- 提交后一次性创建 N 个独立图片任务
- 结果逐个出现在右侧缩略图区

### F2: 并发控制

**位置**: 配置中心(ConfigScreen)的"并发数"改为真实配置

- 从本地 mock state 改为:
  1. 前端从 `capabilities` 或配置接口读取最大并发数
  2. 批量提交时,前端控制并发请求数(如一次发 3 个,完成后发下一批)
  3. 或后端提供批量提交接口,后端内部管理并发
- 用户可设置 1-8 的并发数

**接受标准**:
- 设置并发数为 3,批量提交 9 个任务 → 第一批 3 个并行,第二批 3 个...
- 右侧缩略图区实时显示每个任务的状态

### F3: 比例预设选择

**改为可视化比例选择器**,替换当前裸分辨率下拉框:

| 预设 | 分辨率 | 显示 |
|------|--------|------|
| 1:1 正方形 | 1024x1024 | 方形图标 |
| 4:3 横版 | 1440x1080 | 横矩形图标 |
| 16:9 宽屏 | 1920x1080 | 宽矩形图标 |
| 9:16 竖版 | 1080x1920 | 竖矩形图标 |
| 3:4 竖版 | 1080x1440 | 竖矩形图标 |

- 用小型比例图标+文字展示,不用下拉框
- 默认选中 16:9

### F4: 画质三档

| 选项 | 说明 |
|------|------|
| low | 快速预览,低积分消耗 |
| medium | 标准画质 |
| high | 高清画质,高积分消耗 |

默认 `medium`。

### F5: 模型动态选择

- 从后端 `capabilities.image.models[]` 和 `capabilities.video.models[]` 动态渲染模型列表
- 选中模型后,比例选项和画质选项跟随模型能力过滤
- 必须支持 MiniMax 系列模型

### F6: 缩略图预览+全屏查看

- 右侧缩略图区: 2-3 列网格,每张缩略图约 120-160px 宽度
- 点击缩略图 → 弹出全屏预览弹窗:
  - 大图/视频播放
  - 左右箭头切换
  - 下载按钮
  - "加入视频参考篮"按钮
  - 关闭(ESC / 点击遮罩)
- 缩略图上有勾选框,支持批量选中后一键加入参考篮

### F7: 视频缩略图展示

- 视频 Tab 右侧任务卡片改为缩略图模式:
  - 已完成: 显示视频封面缩略图 + 下载按钮
  - 处理中: 进度条 + 预估剩余时间
  - 排队中: "排队中"占位图 + 队列位置
  - 失败: 错误信息卡片

### F8: 视频提示词优化打磨

- AI 润色按钮目前是前端 mock(正则补全标签),改为调用后端 AI 接口
- 润色结果可预览对比,选择接受或保持原提示词
- 润色维度覆盖视频六要素(主体/动作/运镜/氛围/画质/时长)

### F9: 代码拆分

将 `AdminMediaWorkbenchScreen.tsx` 拆分为:

```
src/components/screens/
  AdminMediaWorkbenchScreen.tsx         主容器,布局+Tab切换
  admin-media-workbench/
    ImageGenPanel.tsx                   图片操作面板
    VideoGenPanel.tsx                   视频操作面板
    ThumbnailPanel.tsx                  缩略图面板(图片)
    VideoRunPanel.tsx                   视频任务面板
    RatioSelector.tsx                   比例预设选择器
    ModelSelector.tsx                   动态模型选择器
    PromptBatchInput.tsx               批量提示词输入
    ImagePreviewModal.tsx              全屏预览弹窗
    AssetBasketPanel.tsx               素材篮/历史面板
    StatusCards.tsx                    状态卡片
```

## 四、数据/接口改动要点

### 后端需配合

1. **动态模型列表**: 确认 `/admin/media-workbench/capabilities` 已返回完整 models 数组
2. **批量图片提交**: 新增 `POST /admin/media-workbench/images/runs/batch` 或让前端并发调单任务接口(前端控制并发数)
3. **并发配置**: 提供读/写并发数的配置接口,或从 capabilities 返回值中读取
4. **视频 AI 润色**: 新增 `POST /admin/media-workbench/videos/polish` 或复用现有润色接口
5. **MiniMax 模型接入**: 后端 provider 需对接 MiniMax 图片/视频生成 API

### 前端接口改动

```typescript
// 批量图片请求(新增)
interface ImageWorkbenchBatchRequest {
  requests: ImageWorkbenchRunRequest[];   // 多个独立任务
  concurrency?: number;                   // 并发数
}

// 比例预设(新增)  
type AspectRatio = "1:1" | "4:3" | "16:9" | "9:16" | "3:4";
```
