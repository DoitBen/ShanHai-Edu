# 多角色协作决策台账

## 使用规则

- 记录影响项目方向、角色分工、业务范围、验收口径或协作流程的重要结论。
- 普通过程记录不写入本台账。
- 决策被修改时，不删除旧记录，新增一条变更记录并说明原因。
