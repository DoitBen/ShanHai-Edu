# 多角色交付物模板

## 使用规则

- 每个角色输出正式结果时，优先使用对应模板。
- 简单任务可以删减空栏目，但不得省略“结论、依据、下一步、验收口径”。
- 产生跨角色共同结论时，同步更新 `workflow\multi-agent\shared-facts.md`。
- 产生重要决策时，同步更新 `workflow\multi-agent\decisions.md`。
- 产生角色冲突时，同步更新 `workflow\multi-agent\conflicts.md`。
