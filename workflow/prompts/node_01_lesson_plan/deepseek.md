## 输出要求

### 第一层：教案正文（6个字段）

| 字段 | 含义 | 注意 |
|---|---|---|
| `textbook_anchor` | 教材依据 | 必须精准到「{教材版本}{年级}{上下册}第X单元/页码 课题《X》」 |
| `teaching_objectives` | 教学目标 | 围绕新课标 2022 核心素养，3 条左右，必须可观察可检测 |
| `key_difficulty` | 教学重难点 | 重点和难点分别陈述 |
| `teaching_flow` | 教学流程 | 导入 / 探究 / 练习 / 小结四段式，每段一句话 |
| `blackboard_design` | 板书设计 | 一屏内呈现核心概念，不超过 50 字 |
| `intro_designs` | 三类九套导入视频策划卡 | 见下方详细说明，这是本步骤最重要的输出 |

### 第二层：三类九套导入视频策划卡（核心）

**每类（科普 / 应用 / 故事）生成 3 套，共 9 套。**

导入视频首先是吸引型短视频，不是教学讲解前置稿。视频主体可以与课堂教学流程完全无关，只在结尾通过课程锚点自然接回本课。

每套策划卡必须有两层结构：

**层一：独立创意（视频本身）**
- `hook`：视频开场如何抓住学生（冲突/悬念/奇妙发现/现实问题）
- `video_theme`：视频独立主题（可以完全不像"数学课"）
- `eye_catch_tag`：新奇特标签（3个词以内，体现差异化）

**层二：课堂接入（锚点层）**
- `anchor_to_lesson`：**课程锚点**（见下方定义，这是最重要的字段）
- `classroom_entry_question`：课堂落点问题（视频结束后老师第一句话）
- `no_pre_teach`：不提前讲解的内容（哪些课堂探究内容视频不能碰）
- `entry_position`：接入教案的位置（在哪个教学环节播放）

## 课程锚点定义（必须理解，否则整条视频链质量无法保证）

> **课程锚点是短视频和本课教案之间唯一必须对齐的连接点。**
> 它只负责把一个独立、有吸引力的视频主题，最后自然接回本课学习任务，**不负责提前讲解知识点**。

课程锚点回答的问题：
> **这个视频最后，通过什么现象、问题、物品、冲突或任务，和本课课题发生关系？**

### 合格锚点示例

| 课题 | 合格的锚点写法 |
|---|---|
| 5以内数的认识 | 小兔子不知道5个萝卜要跑几趟才能搬完，引出"数清楚才能解决问题" |
| 认识三角形 | 桥梁、塔吊、屋顶反复出现三角形，引出"为什么它们都选三角形" |
| 平均分 | 两个小朋友分饼干分不公平吵起来，引出"怎样分才算公平" |
| 20以内退位减法 | 小店老板找零找错了，引出"怎么快速算出要找多少钱" |

### 不合格锚点示例（禁止这样写）

| 不合格写法 | 问题 |
|---|---|
| "自然引出本课数学内容" | 太模糊，AI无法生成具体结尾画面 |
| "让学生理解5以内数的含义" | 这是教学目标，不是锚点 |
| "教学目标对应点：认识1-5" | 禁止用此说法替代课程锚点 |
| "视频讲完1-5怎么数，再进入课堂" | 提前讲解了知识点，违反视频独立性 |
| "引出课堂探究活动" | 把课堂流程搬进视频 |

## intro_designs 完整字段结构

```json
{
  "design_id": "design_science_01",
  "type": "science",
  "title": "方案名（10字内）",
  "video_theme": "视频独立主题（视频讲什么，不必和课堂直接相关）",
  "hook": "视频开场钩子（50字内，描述开场冲突/悬念/奇妙发现）",
  "eye_catch_tag": "新奇特标签（3词内）",
  "anchor_to_lesson": "课程锚点：这个视频最后通过[具体现象/物品/冲突/疑问]，引出[课题的核心学习任务]（15-40字，必须具体）",
  "classroom_entry_question": "课堂落点问题：视频播完后老师第一句话（一个具体问题）",
  "no_pre_teach": "不提前讲解的内容（列出哪些知识点视频不能碰）",
  "entry_position": "接入教案的位置（在哪个教学环节之前播放）",
  "recommend_score": 88,
  "recommend_reason": "推荐理由（适配度/吸引力/可制作性/接入自然度）",
  "risk_note": "适配风险（可选）"
}
```

## 红线约束

- 教学目标不得写"了解/知道"这种空目标，必须可观察可检测
- 板书设计不得超过 50 字
- 钩子描述里**不得出现真人未成年人、真实课堂场景**（R045）
- `anchor_to_lesson` 不得写成教学目标、教案关联点、教学目标对应点
- `anchor_to_lesson` 必须是具体的现象/物品/冲突/疑问，不得是抽象描述
- 视频不得提前讲解本课核心定义、方法或结论
- 9 套方案的锚点必须各不相同
- 不得在本步骤输出完整视频旁白、视频剧本、分镜脚本
