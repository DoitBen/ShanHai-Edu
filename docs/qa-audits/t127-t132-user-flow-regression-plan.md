# T127-T132 教材库与工作区用户态重构回归计划

## 1. 测试目标

验证 T127-T132 是否真正完成以下目标：

- 教材库选择和上传教材都进入同一套目录/知识点流程。
- 人教版一年级上册目录项、页码范围、知识点资产包可信。
- 教材内容、教案、视频方案命名清楚。
- 创建项目后的工作区不再是工程节点调试台，而是教师可理解的备课步骤。
- 普通用户主界面不暴露 `StateEngine`、`schema`、JSON、manifest、R010、输出路径、安全模式等工程信息。

## 2. 测试前置条件

启动真实 API 模式：

- API 使用隔离 storage。
- Web 使用真实 API 模式。
- 使用 fixture PDF：人教版小学数学一年级上册。
- 不要求真实视频 provider 成功。
- 不要求任意教材泛化。

测试必须记录：

- API/Web 端口。
- storage 目录。
- 项目 ID。
- 教材 ID。
- 知识点 ID。
- 浏览器截图路径。
- 控制台 error/warn。

## 3. 后端验证

### 3.1 教材目录解析

必须验证：

- 教材库返回“人教版 / 小学数学 / 一年级 / 上册”。
- 目录项至少包含：
  - 数学游戏
  - 5以内数的认识和加、减法
  - 6~10的认识和加、减法
  - 认识立体图形
  - 11~20的认识
  - 20以内的进位加法
  - 复习与关联
- 每个目录项包含教材页码范围和 PDF 页码范围。
- 课时知识点挂在目录章节下。

### 3.2 知识点资产包

必须验证：

- 选择知识点后有页段 PDF 或页段截图。
- 页段 PDF 不是整册 PDF。
- Markdown 包含教材结构化内容。
- Markdown 记录教材页码和 PDF 页码。
- 资产包状态未人工确认前不能是 approved。

### 3.3 教案来源追溯

必须验证教案生成结果包含：

- 当前教材 ID。
- 当前教材版本 ID。
- 当前知识点 ID。
- 页段 PDF 路径。
- MinerU Markdown 路径。
- 参考教案 ID（如果选择了参考教案）。

## 4. 新建项目页浏览器验证

必须覆盖：

1. 教材库下拉框可见。
2. 教材下拉项显示“人教版 / 小学数学 / 一年级 / 上册”。
3. 上传新教材入口可见。
4. 选择教材后加载目录/知识点下拉。
5. 选择知识点后字段自动回填。
6. 目标受众默认“一年级学生”。
7. 核心知识点通过按钮/抽屉查看，不常驻铺开。
8. 教材内容通过按钮打开 Markdown 预览。
9. 教材页段通过 PDF 阅读器或截图预览。
10. 关键词为标签多选，支持自定义。
11. 预计时长支持下拉和自定义输入。
12. PPT 结构为固定模板下拉。
13. 输出路径、安全模式不出现在普通用户主界面。
14. 复制、保存、确认、解析完成有 toast 或反馈。

## 5. 工作区浏览器验证

必须覆盖：

1. 顶部流程为用户态步骤：
   - 项目信息
   - 教材内容
   - 教案生成
   - 导入视频方案
   - PPT 草稿
   - 视频生成
   - 最终交付
2. 已完成步骤可点击回看。
3. 当前步骤可操作。
4. 未解锁步骤灰色锁定，不允许进入详情。
5. 点击未解锁步骤只提示先完成上一阶段。
6. 当前步骤主区域显示：
   - 这一步要做什么。
   - 用户现在需要做什么。
   - 当前结果。
   - 下一步主按钮。
7. 教案以 Markdown 编辑/预览展示。
8. 视频方案、分镜、PPT 等节点显示用户可读摘要，不直接显示 JSON。
9. 开发诊断默认隐藏。
10. 展开开发诊断后才允许看到 StateEngine、schema、日志、原始 JSON。

## 6. 红线检查

普通用户主界面不得出现：

- `StateEngine`
- `schema`
- `JSON`
- `R010`
- `manifest`
- `dependency_gate`
- `输出路径`
- `安全模式`
- `provider`
- `node_id`

若出现，测试结论为不通过。

## 7. 证据要求

测试报告必须包含：

- 教材库下拉截图。
- 知识点选择截图。
- 教材页段 PDF 或截图预览证据。
- MinerU Markdown 预览证据。
- 工作区用户态步骤截图。
- 未解锁步骤点击反馈截图。
- 教案 Markdown 编辑/预览截图。
- 开发诊断默认折叠截图。
- 浏览器 console error/warn 记录。
- 后端测试命令结果。
- 前端 tsc/lint/build 结果。

## 8. 通过标准

全部满足以下条件才通过：

1. 后端目录、资产包、教案来源追溯测试通过。
2. 前端 tsc/lint/build 通过。
3. 浏览器核心路径通过。
4. 红线检查无违规。
5. 控制台无阻断性 error/warn。
6. 测试报告能明确说明剩余风险。

## 9. 不在本轮范围

- 任意教材自动泛化。
- 生产级教材库后台。
- 生产级权限/RBAC。
- 真实视频 provider 成片验收。
- Cloud Run/正式上线验收。
