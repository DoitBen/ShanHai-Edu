# 风险与不确定性

已识别的风险、未解决的开放问题、未来需要验证的假设。

---

## A. 已识别风险（按概率 × 影响排序）

### A1. LLM 输出 JSON 格式不稳定（高概率 + 中影响）
- **现象**：DeepSeek 在长 prompt 下偶尔输出 markdown 包装的 JSON
- **兜底**：markdown 剥离 + ajv 校验 + 失败重试 1 次 + 切 fallback
- **未知**：长期 provider 升级后行为变化（DeepSeek 改输出格式）

### A2. 视频生成 API 不稳定（高概率 + 高影响）
- **现象**：omni_flash 排队、超时、内容审核驳回、生成质量差
- **兜底**：首帧测试机制 + 6 段并发 + 失败单独重试 + 部分失败可接受
- **未知**：omni_flash 服务的长期可用性（创业公司，可能关停）

### A3. 跨 provider prompt 质量不一致（中概率 + 中影响）
- **现象**：DeepSeek 跑通的 prompt 切到 GPT 质量崩
- **兜底**：每节点 default + fallback 都验证、AI 接入 0.5 人专职调优
- **未知**：上线后用户用偏冷门的 provider 组合时质量

### A4. 中文 TTS 选型未定（中概率 + 高影响）
- **影响**：第 8 步无法跑通
- **兜底**：第 1 月内必须选型完成
- **候选**：阿里云 / 火山引擎 / 腾讯云 / Azure
- **决策标准**：男声音质 + SSML 控制 + 价格 + 中国大陆可用

### A5. ppt-master 集成复杂度（中概率 + 中影响）
- **现象**：现有 ppt-master 是独立工具链，输入/输出契约不清
- **兜底**：先按 "调用 CLI + 读输出文件" 对接，不深度集成
- **未知**：ppt-master 内部演进时，我们的对接代码会不会跟着挂

### A6. 教研员对 13 字段嫌多（中概率 + 高影响）
- **现象**：填表负担大，用户嫌烦
- **兜底**：AI 默认填好所有字段，用户只看不爽的格改
- **未知**：第一批用户的真实反应（要内测才知道）

### A7. 现有 9 个门禁脚本路径硬编码（中概率 + 中影响）
- **现象**：scripts/*.py 可能引用了具体 Windows 路径
- **兜底**：M9 阶段第一件事是审一遍所有脚本
- **未知**：脚本维护方是否配合改

### A8. 飞轮冷启动质量（中概率 + 中影响）
- **现象**：第一个项目没历史样本可注入，AI 输出质量底
- **兜底**：fallback 到 schema 默认生成
- **未知**：第一批用户对"还没飞轮"时的产品质量是否能接受

### A9. SQLite 并发写（低概率 + 低影响）
- **现象**：单项目多标签同时编辑可能锁库
- **兜底**：v1 检测到第二标签提示用户关闭

### A10. 磁盘空间（低概率 + 中影响）
- **现象**：视频/图片堆积撑满硬盘
- **兜底**：启动检查 + 阈值预警 + 用户可归档老项目
- **未知**：用户磁盘普遍多大、归档需求多频繁

## B. 未解决的开放问题（v1 上线前必须定）

### B1. 中文 TTS 选型
- 候选：阿里云 / 火山引擎 / 腾讯云 / Azure
- 决策标准：男声音质 + SSML 控制 + 价格 + 中国大陆可用性
- 责任：产品 + 全栈共同决策
- 截止：第 1 月内

### B2. 教程内容由谁写
- 候选：教研团队（懂教学法但不懂产品）/ 产品团队（懂产品但不懂教学法）/ 半外包
- 影响：教程质量直接影响外销
- 截止：第 2 月

### B3. 内部部署形态
- 候选：单机 exe / Docker Compose / 内网服务
- 影响 IT 部署和数据安全
- 截止：第 1 月

### B4. 磁盘配额策略
- 一个项目占多大、什么时候提示用户清理
- 截止：第 2 月

### B5. 多标签并发的具体处理
- 禁用第二标签 vs 只读模式
- 截止：M8 frontend 开发时

### B6. manifest.md 文件还要不要保留
- SQLite 是真源后，manifest.md 是否导出为只读视图
- 影响向后兼容
- 截止：M1 storage_layer 开发时

### B7. 错误打包反馈的脱敏规则
- 哪些字段不能上报（API key、用户原话等）
- 影响合规和外销
- 截止：第 2 月

### B8. 新规范发布时的回灌策略
- 现有项目要不要按新规范重审
- 影响产品演进路径
- 截止：v1.x

### B9. 对标 PPT 的 skill 选型
- 用哪个现成方案（用户说"不重复造轮子"）
- 截止：第 2 月

### B10. 逐页审查智能体的"轻量 / 重量"两级具体怎么划分
- 轻量版每页跑、重量版每 4 页跑
- 截止：M6 supervisor 开发时

### B11. 教学法负责人指派
- 谁为规范持续更新负责
- 影响 v1.x 教学法演进
- 截止：v1 上线前

### B12. 课后反馈字段设计
- 第二次使用弹窗里问哪几个问题
- 影响飞轮信号质量
- 截止：第 3 月

### B13. 冷启动 UX
- 第一次进来什么也没有，怎么让用户用上飞轮 / 偏好画像
- 截止：M8 frontend 开发时

## C. 待验证的假设（v1 内部用时收集反馈）

### C1. 用户能接受"逐页审查智能体"自动重生
- **假设**：用户喜欢"产品筛过一遍的页面"
- **风险**：可能用户觉得"AI 抢了我的判断权"
- **验证方式**：第 3 月内测时观察 override 频率

### C2. 用户能接受"上游变更下游全降级"
- **假设**：用户接受"自己重审"
- **风险**：可能用户嫌烦
- **验证方式**：观察"回头修改"的频次和后续操作

### C3. 飞轮 few-shot 注入能让 AI 越用越像用户
- **假设**：3 个 approved 样例足以让风格收敛
- **风险**：可能样例太少没效果，或太多让 AI 过拟合
- **验证方式**：第 3 月内测后用 A/B 对比（注入 vs 不注入）

### C4. 用户主动写反馈的比例 > 30%
- **假设**："上完课反馈"在第二次使用时填写率高
- **风险**：可能填写率 < 10%，飞轮主品信号缺失
- **验证方式**：内测后统计

### C5. 中文男声 TTS + omni_flash 视频拼接体验震撼
- **假设**：用户拿到视频时觉得"卧槽"
- **风险**：可能拼接痕迹明显、音视频不同步
- **验证方式**：第 3 月跑完整链路后用户演示

### C6. SQLite 单机够用
- **假设**：内部教研团队规模下，SQLite 性能不是瓶颈
- **风险**：可能某个团队同时跑 10 个项目卡顿
- **验证方式**：负载测试 + 内测监控

### C7. 教研团队会主动维护 workflow.yaml / rules
- **假设**：教学法负责人能学会改 yaml
- **风险**：可能他们不愿学技术细节
- **验证方式**：v1 上线后第一次规范变更时观察

### C8. 角色字典的"多视角+服装锁定+禁真人"足以规避肖像权
- **假设**：法律意义上不构成侵权
- **风险**：法务给出不同意见
- **验证方式**：v1 上线前法务 review

## D. 不确定性（v1 之后才能知道）

### D1. 外销定价模型
- 按项目计费 / 按月订阅 / 按 API 用量分成
- 取决于客户类型和飞轮黏性

### D2. 飞轮独立 vs 共享
- 每个客户飞轮独立（隐私安全但飞轮慢）
- 共享底层（飞轮快但抹平个性）
- 可能分层：公共底层 + 客户层私有

### D3. 教程系统的形态
- 独立 PDF / 视频教程 / 产品内嵌 hover 卡片 / 上下文动态
- 取决于内部教研团队的使用习惯反馈

### D4. 智能体对话流的价值
- 是 v2 必做还是可选
- 取决于网页版用熟后用户的反馈

### D5. 跨学科扩展（数学 → 语文 / 英语）
- workflow.yaml 能否扩展
- 取决于产品稳定后团队精力

## E. 监控建议（v1 上线后跑起来后必须看的指标）

### E1. 飞轮指标
- 每用户的 approved 版本数
- approve 后又改了的比例
- override 频率 by 规则
- 偏好画像访问频率

### E2. 质量指标
- 第几版 approved 的分布（理想是 v1 多）
- 逐页审查智能体 hard_block 命中率
- 用户反馈分数分布

### E3. 性能指标
- 端到端耗时（从创建项目到最终交付）
- 各节点耗时分布
- LLM 调用成本累计

### E4. 错误指标
- 错误日志频率 by 错误类型
- provider 切换频率
- 视频生成失败率

### E5. 留存指标
- 用户做完第 N 个项目的留存率
- 反馈填写率
- 项目从开始到完成的转化率

---

## 总结

风险大致分四类：
1. **技术风险**（LLM / 视频 / TTS / 集成）—— 兜底机制完整
2. **产品假设风险**（用户接受度 / 飞轮效果）—— 内测验证
3. **资源风险**（开发资源、教学法资源）—— 第 1 月必须确定
4. **未来不确定**（外销、定价、扩展）—— 等数据说话

整体判断：风险可控，兜底充分，没有 v1 上不了线的死结。
