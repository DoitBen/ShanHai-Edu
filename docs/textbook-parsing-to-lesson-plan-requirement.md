# 教材解析到教案生成链路需求说明

日期：2026-06-20

## 背景

用户提供了一套一年级上册人教版数学教材与“5 以内数的认识”教案样例，作为项目本地测试资料。该资料用于验证从教师上传教材 PDF 到生成公开课教案 Markdown 的完整前置链路。

## 已纳入项目的测试资料

测试资料目录：

```text
fixtures\textbook-parsing\renjiao-grade1-volume1-2024
```

包含：

- `1上-人教版小学数学课本（2024新版）.pdf`：教材 PDF。
- `5以内数的认识_结构化文字教案.md`：目标知识点抽取后的结构化 Markdown 样例，作为教材片段抽取质量参考。
- `5以内数的认识_公开课教案.pdf`：最终教案展示样例，仅作效果参考，不作为固定模板。

## 已纳入项目的解析技能

项目内新增技能副本：

```text
skills\pdf
```

默认解析路线：

- 使用 `skills\pdf` 的 MinerU 路由。
- 本机已探测 MinerU 可用：`mineru, version 3.2.0`。
- 默认用于教材 PDF 的高保真结构化解析，而不是简单全文文本抽取。

## 目标工作流

用户真实使用路径：

1. 教师上传教材 PDF。
2. 点击“解析教材”按钮。
3. 后端调用项目内 `skills\pdf` / MinerU 对教材做大纲解析。
4. 解析并回填基础字段：
   - 学科
   - 年级
   - 教材版本
   - 上下册
   - 课型可继续手工选择
5. 前端允许教师手工修改回填字段。
6. 解析整本教材知识点，更新“课程知识点”下拉框。
7. 教师选择某个知识点。
8. 后端再次基于 MinerU 结果锚定该知识点对应页码/章节，抽取对应教材内容。
9. 输出结构化 Markdown，作为后续教案生成节点输入。
10. 教案生成工作流基于该 Markdown 生成公开课教案 Markdown。

## 关键数据标准

教材大纲解析输出建议：

```json
{
  "textbook_meta": {
    "subject": "math",
    "grade": "1",
    "textbook_version": "renjiao",
    "volume": "shang",
    "title": "人教版小学数学一年级上册"
  },
  "knowledge_points": [
    {
      "id": "kp_001",
      "title": "5以内数的认识",
      "unit": "5以内数的认识和加、减法",
      "page_start": 14,
      "page_end": 23,
      "pdf_page_start": 19,
      "pdf_page_end": 28,
      "keywords": ["1-5", "比大小", "第几", "分与合"]
    }
  ]
}
```

知识点锚定抽取输出建议：

```json
{
  "knowledge_point_id": "kp_001",
  "title": "5以内数的认识",
  "source_pages": {
    "textbook_pages": "14-23",
    "pdf_pages": "19-28"
  },
  "markdown_path": "storage/.../knowledge-points/kp_001.md",
  "markdown": "# 《5以内数的认识》图文教材结构化整理\n..."
}
```

教案生成节点输入：

```json
{
  "textbook_markdown": "...",
  "project_meta": {},
  "teaching_preferences": {}
}
```

## 边界说明

- `5以内数的认识_公开课教案.pdf` 只作为效果参考，不是模板。
- `5以内数的认识_结构化文字教案.md` 是教材片段抽取质量参考，可作为测试断言来源。
- 首阶段先跑本地 MinerU 和 fake LLM/provider，不承诺生产级识别准确率。
- 用户可修改自动回填字段，前端不得把解析结果视为不可变事实。
- 教材 PDF 和解析产物属于测试资产与本地运行产物，上线前需要补文件大小、格式、版权和存储策略。

## 验收口径

本地演示通过条件：

- 上传教材后能触发“解析教材”。
- 可识别并回填一年级、人教版、上册、数学等基础字段。
- 可生成知识点下拉选项，至少包含“5以内数的认识”或可对应到该学习段。
- 选择知识点后能产出 Markdown。
- 该 Markdown 能进入教案生成节点，生成一份公开课教案 Markdown。
- 前端允许人工改字段、改知识点选择。
