# Flywheel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 `docs/architecture-optimization-v2.md` 第 4 周 Flywheel 最小闭环，让 approve、approved 后 edit、warning override、feedback 都进入可查询数据表。

**Architecture:** 新增轻量 `FlywheelService`，由 `WorkflowService` 在现有 StateEngine / RuleExecutor 成功路径后记录事件。SQLite per project 内新增四张表，并通过调试查询 API 暴露当前项目飞轮事件；本阶段不做跨用户检索、不做 prompt 注入。

**Tech Stack:** FastAPI、SQLite、pytest、现有 `ProjectStore` / `WorkflowService`。

- 若编辑前状态为 `approved` 且有当前版本，写入新版本后记录 post approve edit。
